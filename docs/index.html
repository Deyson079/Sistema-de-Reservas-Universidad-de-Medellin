Reservas Deportivas

Mockups de la plataforma de reservas de canchas polideportivas de la Universidad de Medellín. Son páginas estáticas para revisar el diseño en el navegador o importarlas a Figma.

Inicio (landing)Desktop 1440 y móvil 390. Usa la barra inferior para ver las dos mesas de trabajo. Design SystemColores, tipografía, espaciado, grid y componentes.
La aplicación completa (registro, reservas, pagos y paneles) necesita servidor y base de datos, así que no corre en GitHub Pages: se publica en Vercel o se ejecuta en local con npm run dev. Código: github.com/Deyson079/Sistema-de-Reservas-Universidad-de-Medellin.
